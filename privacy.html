Kebijakan Privasi NexaBuild

Terakhir diperbarui: 13 November 2026

NexaBuild adalah aplikasi web statis yang membantu membuat APK/AAB melalui akun GitHub milik pemakai. NexaBuild tidak mengoperasikan server build sendiri dan tidak menjalankan analitik iklan.

Token GitHub

  • Personal access token disimpan di localStorage pada browser/perangkat yang digunakan.
  • Aplikasi mengirim permintaan API yang memerlukan token langsung ke api.github.com. Jika pemakai memilih repository sumber GitHub privat, secret SRC_TOKEN juga digunakan oleh GitHub Actions untuk melakukan clone melalui HTTPS ke github.com.
  • Tidak ada token yang sengaja dikirim ke layanan font atau CDN. Namun, skrip pihak ketiga yang dimuat dari CDN berjalan dalam konteks halaman dan secara teknis dapat mengakses penyimpanan browser. Library JavaScript dipatok versinya; stylesheet Google Fonts dimuat dari Google Fonts. Gunakan deployment resmi yang sumbernya dapat diperiksa.
  • Tombol “Putuskan” menghapus token dari penyimpanan lokal, tetapi tidak mencabut token di GitHub. Untuk mencabutnya, hapus token dari GitHub Settings → Developer settings → Personal access tokens.

Proyek dan hasil build

  • Build berjalan di GitHub Actions pada repository apk-builder milik pemakai.
  • Repository build baru dibuat private. ZIP sumber yang diunggah menjadi commit dan penghapusan file setelah build tidak menghapus salinannya dari riwayat Git. Pertahankan repository tersebut private.
  • Jika pemakai memilih repository sumber privat, akses sumber diberikan melalui secret SRC_TOKEN hanya pada langkah clone.
  • Kompilasi sumber dan signing berjalan pada runner terpisah. Secret keystore dan token rilis hanya tersedia pada runner signing, bukan pada proses kompilasi sumber.
  • APK/AAB, log build, ikon, konfigurasi, dan riwayat repository dikelola oleh GitHub sesuai pengaturan akun dan repository pemakai.

Layanan pihak ketiga

NexaBuild memuat dependensi versi tertentu dari jsDelivr untuk membaca ZIP, enkripsi secret, dan membuat QR, serta Google Fonts untuk tipografi. Browser dapat menghubungi domain tersebut saat fitur terkait digunakan.

Kontrol pemakai

Pemakai dapat memutuskan koneksi, mencabut token di GitHub, menghapus repository build, dan menghapus riwayat/artefak melalui GitHub. Menghapus data browser tidak menghapus data yang telah disimpan di GitHub.

Perubahan kebijakan

Kebijakan ini dapat diperbarui ketika perilaku aplikasi atau layanan yang digunakan berubah. Tanggal pembaruan ditampilkan di bagian atas halaman.
